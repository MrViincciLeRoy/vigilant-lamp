# Vigilant Lamp Project\n\nVigilant Lamp is an automated horror story and audiobook generator. It uses a local LLM to generate long-form psychological horror stories, converts them into WAV audio files, and sends progress updates and final files via Telegram.\n\n## Key Features\n- Automated horror story generation using a local LLM\n- Conversion of stories into WAV audio files\n- Progress updates and file sharing via Telegram\n\n## Tech Stack\n- Python 3.x\n- Llama CPP\n- Kokoro TTS\n- NumPy\n- SoundFile\n- Requests\n- Telegram API\n\n## Installation\nTo install the required libraries, run the following command:\n```bash\npip install llama-cpp-python numpy soundfile kokoro-tts requests\n```\n\n## Usage\n1. Set the environment variables:\n   - TELEGRAM_BOT_TOKEN: Your Telegram bot\'s API token.\n   - TELEGRAM_CHAT_ID: The chat ID where notifications and files will be sent.\n2. Ensure you have the GGUF model file available. This script is configured to download it automatically from the Hugging Face Hub.\n3. Run the `horror_generator.py` script to start the generation process.\n\n## Required Environment Variables\n- TELEGRAM_BOT_TOKEN: Your Telegram bot\'s API token.\n- TELEGRAM_CHAT_ID: The chat ID where notifications and files will be sent.
